# Blue Whale Maid Desktop Pet Template

This repository contains an original, desktop-pet-ready character template inspired by the three supplied references.

## Asset

- [`assets/blue-whale-maid-pet.svg`](assets/blue-whale-maid-pet.svg) — a transparent, scalable SVG of a front-facing blue whale maid.

The compact standing pose, oversized head, symmetrical silhouette, and short feet closely follow the supplied desktop-pet reference. Distinct visual features—tail, layered hair, face, outfit, apron, hands, and shoes—make the illustration straightforward to adapt into animation frames later.

## Preview

Open the SVG directly in a browser or an illustration editor. Because the background is transparent, it can be exported to PNG at any required desktop-pet resolution.
