# Blue Whale Maid Desktop Pet Template

This repository contains an original, desktop-pet-ready character template inspired by the three supplied references.

## Asset

- [`assets/blue-whale-maid-pet.svg`](assets/blue-whale-maid-pet.svg) — a transparent, scalable SVG of a seated blue whale maid.

The silhouette uses a compact seated pose so it can sit naturally near the bottom edge of a desktop. Distinct layers and grouped visual features—tail, hair, face, outfit, and hands—make the illustration straightforward to adapt into animation frames later.

## Preview

Open the SVG directly in a browser or an illustration editor. Because the background is transparent, it can be exported to PNG at any required desktop-pet resolution.
